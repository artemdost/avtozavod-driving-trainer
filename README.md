# Автозавод — тренажёр экзамена ГИБДД

Браузерный тренажёр практического экзамена на реальной карте Автозаводского района Нижнего Новгорода.

- `index.html` — 2D-версия (вид сверху)
- `index3d.html` — 3D-версия (вид из кабины)

Управление: стрелки / WASD, Q и E — поворотники, пробел — ручник, Esc — пауза.

Данные карты: © участники OpenStreetMap, лицензия ODbL (https://www.openstreetmap.org/copyright).
